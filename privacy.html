隐私政策

工具输入

11 个工具的文本与文件在当前浏览器内处理，本站没有用于上传这些输入并代为处理的服务。剪贴板、文件选择和下载由你的操作触发。

访问请求与统计

加载网站会向托管/CDN 服务请求页面、样式、脚本和资源。服务商可能为内容交付和安全处理 IP、请求时间、路径及浏览器信息。线上已观察到 Cloudflare 分析脚本；工具内容本地处理，不等于访问网站不会产生网络请求。

相关说明见 Cloudflare Web Analytics 与 Cloudflare 隐私政策。日志保留和访问权限取决于实际部署配置。

外部链接与桌面更新

打开 GitHub 等外部链接会向对方发送访问请求。桌面版从本地加载工具，并可能向配置的 GitHub 仓库检查新版本；更新请求不包含工具输入，GitHub 可能接收访问元数据。

广告与变更

本版未接入 AdSense 或广告 Cookie。未来接入前需要更新披露并完成适用的同意配置。隐私问题可通过联系页反馈，请只提交脱敏信息。
