打开 [JSON 格式化工具](../json-format.html)，把下面的脱敏样例粘贴到输入区。输入会自动格式化，也可以点击「格式化」。

```json
{"name":"demo","items":[{"id":"9007199254740993","active":true}]}
```

## 在树形结果中检查结构

展开 items 数组，再展开第一项，应看到 id 字符串和 active 布尔值。点击展开按钮可收起节点；这只改变显示，不删除输入数据。复制或下载得到的是完整结果，不是当前可见节点的片段。

点击「压缩」应得到单行 JSON，字段和值不变。切换为 YAML、XML 或类型定义属于结构转换，需要复核目标格式的语义。

## 先区分语法错误和精度风险

```json
{"name":"demo",}
```

这个样例带有尾随逗号，必须报错。JSON 不支持注释、单引号和尾随逗号。具体报错位置及用语可能因浏览器而异。

```json
{"id":9007199254740993}
```

这个样例语法合法，但数值超出 JavaScript 安全整数范围。本工具会阻止自动格式化、压缩和转换，避免把编号改成另一个值。把编号改为带引号的字符串后，应完整保留 9007199254740993。

## 安全检查的边界

极大指数导致的非有限值也会被拒绝。普通小数仍按 JavaScript 浮点规则处理，本工具不是金融精确计算或任意精度数字转换器。重复对象键也不应作为可靠输入：标准解析会保留后出现的值。

语法通过只说明能解析，不代表字段齐全、签名有效或符合接口契约。处理订单号、账号和数据库 ID 时，优先从源头使用字符串；不要先让其他软件舍入，再尝试在这里恢复。
