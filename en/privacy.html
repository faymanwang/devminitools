Privacy Policy

Tool inputs

Text and files in the 11 tools are processed in your browser. The site has no service that uploads these inputs for processing. Clipboard, local file selection and downloads are triggered by your actions.

Website requests and analytics

Loading the site requests HTML, styles, scripts and assets from its hosting/CDN providers. Providers may process IP addresses, request times, paths and browser metadata for delivery and security. Cloudflare's analytics beacon has been observed on the live site; local processing of tool inputs does not mean that visits generate no network requests.

Cloudflare describes its analytics at Cloudflare Web Analytics and its handling of information in the Cloudflare Privacy Policy. Retention and access depend on the deployed service configuration.

External links and desktop updates

Opening GitHub or other external links sends a request to that service. The desktop application loads the tools locally and may check the configured GitHub repository for new releases. Update checks do not include tool inputs; GitHub can receive request metadata.

Advertising and changes

This release does not include AdSense or advertising cookies. Any future advertising integration requires an updated disclosure and applicable consent configuration before launch. Privacy questions can be raised through the contact page using redacted information.
