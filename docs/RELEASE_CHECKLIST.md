# 发布与审核准备

1. 确认使用 main 基线的本次代码，停止旧 develop/dist 预览；`npm run preview` 直接服务当前静态源码。
2. 运行 `npm run generate:i18n`、`npm run check:site`、`npm test`。生成两次应无额外内容差异。
3. 保持现有首页、导航和工作区；只检查新教程区域、页脚入口及新增文章的局部样式。
4. 联系渠道使用维护者提供的 faymanwang@gmail.com；中英文页面均使用 mailto 链接。Issues 保持关闭，不作为反馈入口。`npm run check:production` 在真实渠道缺失时失败；邮件实际收发仍由维护者验证。
5. 正式发布前核对真实托管/CDN 日志、Cloudflare 分析开关和访问权限；隐私政策不能仅凭本地零请求测试声称线上无统计。
6. 线上核验 `/`、`/en/`、工具、双语说明、`/guides/`、`/en/guides/` 的 HTTPS、200/404、clean URL 重定向、缓存和语言切换。保留 `.html` 相对链接以支持桌面离线。
7. 分别记录 Search Console 的可抓取性和实际索引；不要把本地检查或 sitemap 提交称为已收录。
8. 本次不接广告、不提交 AdSense。后续广告接入单独完成发布商资料、隐私披露、适用同意配置和按钮周围的广告位置验收；网页广告不得进入桌面版。
9. 桌面版重新生成页面后打包，断网测试双语教程和工具。更新检查可能访问 GitHub，但不应发送工具输入。

本次保留既有托管方式；GitHub Actions 在生成和检查通过后才继续发布。未实际部署时，不宣称正式域名的新页面已可访问或审核已通过。
