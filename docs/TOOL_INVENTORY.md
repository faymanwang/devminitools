# main 基线工具盘点

基线：39fc952。保持 11 个工具、中英文各一页，不恢复旧 develop 中已删除的工具。全部工具输入在浏览器处理；页面加载和外部链接仍会联网，线上另有 Cloudflare 分析脚本。

| 工具 | 实际能力与示例 | 边界 |
|---|---|---|
| JSON 格式化 | 自动格式化、树形展开/收起、压缩、复制、下载、YAML/XML/类型转换；示例：`{"id":"9007199254740993"}` | 阻止不安全整数和非有限值；普通小数遵循 Number，重复键保留后值；不是任意精度转换器 |
| JSON 转实体 | Java、Go、C#、Rust、Ruby、XML、YAML；页面提供结构示例 | 共享安全解析；根据样例推断，不能代替语言编译或业务模型设计 |
| 图片压缩 | JPEG/PNG/WebP 静态导出、质量、比例缩小、预览、下载；教程提供透明原图 | JPEG 白底，PNG 无质量参数；核对 MIME；可能变大，不保留动画/元数据 |
| 图片转换 | 从浏览器可解码 JPEG/PNG/WebP/AVIF 转 JPEG/PNG/WebP | 受浏览器编解码支持和内存约束；失败时旧下载失效 |
| 图片合成 GIF | 本地 worker 编码、多帧顺序、时间与尺寸；使用两张测试图片 | 大量/大尺寸图片影响内存与响应时间；不是视频编码工具 |
| 颜色转换 | HEX/RGB/HSL、预览、复制；使用页面示例颜色 | 不处理 ICC 色彩管理、印刷色和所有 CSS 色彩空间 |
| User-Agent 解析 | 浏览器、系统、设备、引擎和常见机器人；页面示例/当前 UA | 启发式识别；可伪造的 UA 不是可信身份或精确硬件检测 |
| 代码对比 | 行差异、空白/大小写选项、高亮、上传和同步滚动；教程含两个两行样例 | 不执行代码、不验证语义；忽略空白按行规范化；大文件使用更多内存 |
| Markdown 预览 | 标题、列表、引用、代码、表格和链接；页面示例 | 自定义子集，不承诺完整 CommonMark；外部链接由用户打开 |
| 多行文本 | 拼接、添加前后缀、引号包裹、去空行；页面示例 | 文本操作不自动理解 SQL、CSV 或其他业务语法 |
| IP 地址 | IPv4/IPv6 格式和地址类别；`192.168.1.1`、`2001:db8::1` | 不是联网地理位置查询；IPv6 不接受 zone ID；地址类别不是可达性证明 |
