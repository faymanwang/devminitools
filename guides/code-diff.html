代码对比：空白和大小写如何影响结果

打开 代码对比工具。选择文本模式，先关闭「忽略空白」和「忽略大小写」，分别粘贴下面两段输入。

左侧原文

const Name = "demo";
return 1;

右侧修改后

const   name = "demo";
return 1;

点击「开始对比」后，第一行应被标为修改，第二行相同。第一行同时存在空白数量和 Name/name 大小写两种差异。

一次只改变一个选项

只启用「忽略空白」时，第一行仍然不同，因为大小写没有被忽略。再启用「忽略大小写」并重新对比，两行都应视为相同。关闭这两个选项，应重新显示第一行差异。

这里的「忽略空白」是对每一行把连续空白替换为一个空格，并去除首尾空白；它不是删除所有空格，也不会合并两行。比如 a b 和 ab 仍是不同文本。

对比不是代码审计

忽略大小写可能掩盖 JavaScript 标识符变化，忽略空白可能掩盖 Python 缩进变化。这些选项用于筛选关注点，不保证程序语义或执行行为相同。语法高亮只是展示，不会运行输入代码。

空输入、只修改一侧或两个相同文件都可以用于核对工具行为。同步滚动只影响浏览位置，不改变比较规则。上传文件在当前浏览器读取；大文件会占用更多内存和计算时间，建议先按函数或段落缩小范围。
